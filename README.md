# ForgeGo 🔨

**ForgeGo** is a developer-first CLI tool written in Go that helps you quickly scaffold production-ready Go projects. Whether you're building an API backend, a CLI tool, or a reusable Go library — ForgeGo helps you start with a clean, idiomatic project structure and boilerplate setup.

> ⚙️ Currently under active development. MVP coming soon.

## ✨ Features (Planned)

- Scaffold Go projects via interactive CLI
- Supports multiple project types: API, CLI, Library
- Clean and extensible folder structures
- Optional Git init, go.mod setup, Dockerfile, and more
